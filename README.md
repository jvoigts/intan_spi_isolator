# intan_spi_isolator
inline isolator for intan SPI cables
We're aiming or  IEC 60601-1,  2x MOPP ?

We'll simply do a two-direction LVDS isolation with these: https://www.digikey.com/en/products/detail/analog-devices-inc/ADN4650BRSZ-RL7/6557306 (double check compliance?)
and power with this https://www.digikey.com/en/products/detail/traco-power/TRV-2-0511M/16630301 (states its iec compliant)

This has the parts in the schematic but no layout etc yet but should give the baic idea.

See the RHD datasheet for how to do the LVDS lines: https://intantech.com/files/Intan_RHD2000_series_datasheet.pdf
